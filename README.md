# Herd RU — русская локализация Laravel Herd (Windows)

Неофициальный перевод интерфейса [Laravel Herd](https://herd.laravel.com) на русский язык.
Патчер заменяет строки по словарю `dict/ru.json` и пересобирает `app.asar`: окна, кнопки,
подсказки, заголовки, меню трея, часть диалогов и уведомлений.

## Требования

- Windows и Laravel Herd в `C:\Program Files\Herd` (проверено на 2.0.4).
- Node.js **22.12+** (проверено на 24.x).

## Установка и обновление

```powershell
npm install
npm run patch
```

`npm run patch` выполняет `extract → apply → pack → install → launch`: собирает перевод,
закрывает Herd, устанавливает архив и запускает приложение. Если прав недостаточно,
установка запросит подтверждение UAC.

Резервная копия оригинального архива создаётся автоматически перед первой заменой.

После обновления Herd перевод пропадает — просто выполните `npm run patch` заново:
оригинал новой версии попадёт в бэкап сам. Строки, которых ещё нет в словаре, останутся
английскими; как их найти и добавить — в разделе «Как изменить перевод».

## Команды

| Команда | npm-скрипт | Действие |
|---|---|---|
| `node patch.js status` | `npm run status` | Версия, состояние установки, бэкап и SHA256 |
| `node patch.js extract` | `npm run extract` | Сверить бэкап и распаковать `work\app` |
| `node patch.js apply` | `npm run apply` | Применить словарь к распакованным чанкам |
| `node patch.js pack` | `npm run pack` | Пересобрать `build\app.asar` |
| `node patch.js install` | `npm run install-patch` | Закрыть Herd и установить сборку |
| `node patch.js backup` | `npm run backup` | Обновить копию оригинала в `backup\` (обычно не нужно) |
| `node patch.js restore` | `npm run restore` | Закрыть Herd и вернуть архив из бэкапа |
| `node patch.js launch` | `npm run launch` | Запустить Herd |

npm-скрипт установки называется `install-patch`, чтобы обычный `npm install` только
устанавливал зависимости. `install` и `restore` подтверждают результат сверкой SHA256,
а при нехватке прав запрашивают UAC. Пути определяются относительно папки проекта —
её можно переносить.

## Резервная копия и откат

Бэкап (`backup\app.asar.orig`) обновляется автоматически при `extract` и `install`.
Патчер никогда не снимает копию с уже пропатченного архива — иначе он затёр бы оригинал;
принудительно — `node patch.js backup --force`.

Для отката: `node patch.js restore`, затем `node patch.js launch`. Восстановление
возвращает **версию из бэкапа**; если она отличается от установленной, `restore`
предупредит о даунгрейде и попросит `--force`. Версии и хэши показывает `npm run status`.

Копируется только `app.asar`: распакованные ресурсы пересобираются при `pack`, поэтому
старую копию `backup\app.asar.orig.unpacked` можно удалить (освободит ~700 МБ).

Патч не меняет исполняемые файлы Herd, PHP/NGINX, сайты, настройки и hosts.

## Структура проекта

| Путь | Назначение |
|---|---|
| `patch.js` | Патчер и все его команды |
| `dict\ru.json` | Словарь перевода |
| `patches\` | Инструменты анализа строк и отчёты |
| `tests\` | Автоматические тесты |
| `AGENTS.md` | Правила проекта и внутренние подробности для ИИ-агентов |
| `backup\`, `work\`, `build\` | Оригинал, распаковка и собранный архив (в git не попадают) |

## Как изменить перевод

Записи живут в секции `translations` словаря `dict\ru.json`:

```json
{
  "Add Site": "Добавить сайт",
  "Failed": { "ru": "Сбой", "files": ["settings-*"] },
  "General": { "ru": "Общие", "skipBefore": "openSettings(" },
  "Next": { "ru": "Далее", "paddedOnly": true }
}
```

- значение-строка применяется во всех чанках; `files` ограничивает замену масками имён;
- `skipBefore` защищает литералы после указанного кода, `paddedOnly` — только текст
  с крайними пробелами;
- совпадение точное, крайние пробелы сохраняются.

Служебные строки переводить нельзя: ключи логики, значения `case`, CSS-классы, пути,
имена продуктов. Если подпись элемента и ключ логики совпадают, переводится только
отображение — пример с вкладками окна «Диагностика» описан в `AGENTS.md`.

После правки словаря: `npm run apply && npm run pack`, затем `npm run install-patch &&
npm run launch`. Перед этим стоит выполнить `npm test`.

## Тесты

```powershell
npm test
```

Используется встроенный `node:test`. Тесты работают во временных каталогах и не трогают
установленный Herd, словарь и локальную сборку, поэтому распаковка Herd для них не нужна.
